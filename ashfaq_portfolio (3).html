02 — Projects

Technical
Projects

// PROJECT_01

3×3 Rubik's Cube Simulator + Solver

Full 3×3×3 cube engine in pure Python. Implements every standard move (U/L/F/R/B/D), middle slices, wide moves, and full cube rotations. Color-renders to terminal via ANSI codes. The solver works through the standard layer-by-layer method — cross, F2L corners + edges, OLL, PLL — all in code, no lookup tables.

Python ANSI Terminal Combinatorics Group Theory
↳ Also replicated in Minecraft Bedrock command blocks
// PROJECT_02

5×5 Rubik's Cube Simulator + Solver

Extends the 3×3 engine to a full 5×5×5 cube with 3 middle layers per axis. Supports 150+ named moves including inner slices (mr1–mr3, mf, mu), wide moves (Wup, WU, etc.), and full-cube rotations (w5u, w5r). Solver reduces 5×5 to 3×3 via center and edge pairing, then applies the 3×3 layer-by-layer method.

Python 150+ Move Types Reduction Method ANSI Render
↳ Also replicated in Minecraft Bedrock command blocks
// PROJECT_03

Nonogram Puzzle Solver

Scalable nonogram (Picross) solver for N×N grids. Two solving engines: a hand-coded constraint-propagation algorithm and an AI-assisted variant. Parses row/column clues, generates all valid placement combinations per line, then iteratively intersects them to lock cells — identical to expert human solving strategy.

Python Constraint Propagation Combinatorics ANSI Colors
↳ Also replicated in Minecraft Bedrock command blocks
// PROJECT_04

4-Bit Combinational Locking Circuit

Designed and wired a 4-bit combinational lock on a physical breadboard using logic gates (AND, OR, NOT, NAND). The circuit accepts a 4-bit binary input and activates an LED output only for the correct key combination — implementing a custom Boolean expression derived from a Karnaugh map minimization.

Digital Logic Breadboard K-Map Logic Gates
↳ Hardware-verified, gate-level implementation
// PROJECT_05

Minecraft Bedrock Command Block Systems

All three software projects — the 3×3 solver, 5×5 solver, and nonogram engine — are recreated inside Minecraft Bedrock Edition using only command blocks, scoreboards, and execute chains. No mods, no scripts; purely the in-game command language. This means encoding cube state in scoreboards, driving move logic through conditional command chains, and rendering the board with wool/concrete block placement.

Minecraft Bedrock Command Blocks /scoreboard /execute /fill
↳ Constraint-driven environment — deepens algorithmic thinking
